📋 Introduction to HTML Lists

Lists are a key way to organize content in HTML. You can create:

  • Unordered Lists (<ul>)
  • Ordered Lists (<ol>)
  • Description Lists (<dl>)

1️⃣ Unordered List Example

🔹 Unordered Lists use <ul> and bullets appear by default.

2️⃣ Ordered List Example

🔢 Ordered Lists use <ol> and display numbers.

3️⃣ Description List Example

📖 Description Lists use <dl> with <dt> for terms and <dd> for definitions.

⚡ Quick Recap

  • <ul> — Unordered List (bullets)
  • <ol> — Ordered List (numbers)
  • <dl> — Description List (term & description)
  • Every item inside <ul> or <ol> uses <li>
