Introduction to HTML Tables 📊

Tables let you display data in rows and columns — perfect for schedules, comparison charts, stats, and more. They’re made using a set of tags that define the table, rows, headers, and data cells.

📝 Pro Tip: Use <thead> for table headers, <tbody> for body rows — it helps browsers and screen readers understand your data better.

🔑 Table Tags Cheat Sheet

  • <table> — The container for your entire table.
  • <tr> — Table Row; groups cells horizontally.
  • <th> — Table Header cell; bold & centered by default.
  • <td> — Table Data cell; normal cell for your content.
  • <thead> — Wraps header rows.
  • <tbody> — Wraps the main data rows.
  • <tfoot> — Optional footer rows.
