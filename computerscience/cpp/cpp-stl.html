💡 Pro Tip: STL saves you from writing your own linked lists, hash maps, and sorting algorithms. It’s battle-tested and highly optimized.

🔧 Core STL Containers

  • vector — Dynamic array (fast random access, slow inserts/removals in middle)
  • list — Doubly linked list
  • map — Key/value pairs (ordered by key)
  • unordered_map — Faster, no order
  • set — Sorted unique values
  • queue, stack, priority_queue — Specialized container adapters

⚡ Algorithms You Can Use

  • sort()
  • find()
  • count()
  • reverse()
  • accumulate() (from <numeric>)
