📖 Key Syntax Rules

  • Every program starts with a package main.
  • import brings in standard libraries (like fmt).
  • The main() function is the program’s entry point.
  • Statements don’t require semicolons (except if on the same line).
  • Use fmt.Println() to print output.
💡 Tip: Go enforces formatting with gofmt. Keep your code clean and consistent.
