GitHub Releases & signed package instructions

Release flow

  • Latest app builds are published to the GitHub Releases page for the public macOS edition repo.
  • Use the .zip package for simple download and installation while beta testing.
  • For a production-ready release, sign the app and publish a notarized DMG or signed ZIP to GitHub Releases.

Signed DMG / ZIP checklist

  • Open the Xcode project and archive the HouseLearning target in Release mode.
  • Sign the app with an Apple Developer certificate and notarize it through Apple.
  • Export a signed DMG or zip archive and upload it to the latest GitHub Release.
  • Keep the release notes updated in the GitHub Releases page and the website download link.
